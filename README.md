# ①課題名
エンゲージメント簡易チェック（リッチVer）

## ②課題内容（どんな作品か）
- 10問の設問にYes/Noで回答すると、現在の仕事へのエンゲージメントをセルフチェックできる（前回同様）

## ③アプリのデプロイURL
https://f-tsuga.github.io/kadai01_jyanken/

## ⑤工夫した点・こだわった点
- 前回提出したものは、回答ボタンがラジオボタンで押しづらかったので、押しやすくかつ押したことが直観的にわかるように改善。
- 回答進捗状況がわかる表示を追加。下にスクロールしても表示され続けるように改善
- 次の一歩ガチャの結果表示を目立つデザインに改善

## ⑥難しかった点・次回トライしたいこと（又は機能）
- 回答進捗状況がわかる表示を追加し表示され続けるように改善したが、途中で消えることがないので見にくい。ここを途中で消えるようにするなど、さらなるUI・UXの改善に取り組みたい。
