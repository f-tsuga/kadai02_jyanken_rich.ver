# ①課題名
エンゲージメント簡易チェック

## ②課題内容（どんな作品か）
- 10問の設問にYes/Noで回答すると、現在の仕事へのエンゲージメントをセルフチェックできる

## ③アプリのデプロイURL
https://f-tsuga.github.io/kadai01_jyanken/

## ⑤工夫した点・こだわった点
- おみくじアプリの説明を聞き、条件分岐を使って、つくってみたかったセルフチェックに応用できそうだなと思ったので挑戦してみました。反転設問も入れYes/Noの選択による得点換算を逆にするなど工夫してみました。最初は得点に応じて高い・普通・低いの３分類にしてみたが、つまらないので、項目ごとにグラフ化するやり方に。また、セルフチェックだけだと、乱数を使う必要がなかったので、最後に最も得点が低かった項目についてのアクションガチャ（３種類）を入れてみました。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- ちゃんとやろうとするとどんどん条件分岐が出てきてしまう＝どんどんコードが複雑になっていってしまう。もっとUI・UXにこだわりたい。
